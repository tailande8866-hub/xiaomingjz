📖 **记账机器人使用说明书**

━━━━━━━━━━━━━━━━━━━━━━

🔢 **一、基础记账操作**

💰 入款记账：
• +1000          ← 入款1000元（默认CNY）
• +1000u         ← 入款1000 USDT
• +1000/7.8      ← 入款1000，汇率7.8
• +1000*12%      ← 入款1000，费率12%
• 张三+1000      ← 为张三入款1000

💸 下发记账：
• 下发5000       ← 下发5000元
• 下发1000R      ← 下发1000人民币
• 张三下发3000   ← 给张三下发3000
• 下发-500       ← 下发修正（减少500）

📦 账单寄存：
• P+2000         ← 寄存+2000
• P-1000         ← 寄存-1000

↩️ 撤销操作：
• -1000          ← 撤销最后一条入款
• 撤销入款       ← 撤销最后入款
• 撤销下发       ← 撤销最后下发
• （回复消息）撤销账单 ← 删除指定账单

━━━━━━━━━━━━━━━━━━━━━━

⚙️ **二、费率汇率配置**

🌐 全局配置：
• 设置汇率8      ← 设置默认汇率
• 设置费率10     ← 设置默认费率（支持负数）
• 费率           ← 查看当前配置
• 配置           ← 查看当前配置

👤 个人配置：
• （回复某人）设置汇率8    ← 设置个人汇率
• （回复某人）设置费率5    ← 设置个人费率
• 删除XX配置     ← 删除个人配置

━━━━━━━━━━━━━━━━━━━━━━

📋 查看账单：

📈 月度汇总：
• 总账单         ← 本月总账
• 上个月总账单   ← 上月总账

💡 **使用提示**

1️⃣ 所有命令直接在群组中发送即可
2️⃣ 回复某人消息可以为其记账或设置个人配置
3️⃣ 支持备注：+1000 这是备注内容
4️⃣ 支持快捷计算：+1000*12% 或 +1000/7.8
5️⃣ 操作人才能进行记账操作
6️⃣ 创始人拥有最高权限
